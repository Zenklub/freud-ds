## Getting Started

É necessário o componente `freud-toast` definido no html e o serviço `FreudMessageService` para a inclusão das mensagens

Toast oferece suporte a várias posições em que o padrão é "top-right".

```html
<freud-toast [position]="'top-center'"></freud-toast>
```

```ts
import { FreudMessageService, FreudMessage } from '@freud-ds/web-components';

export class ComponentDemo {
  constructor(private messageService: FreudMessageService) {}

  confirm() {
    const message: FreudMessage = {
      severity: 'success',
      summary: 'Service Message',
      detail: 'Via MessageService',
    };
    this.messageService.add(message);
  }
}
```

- top-center
- bottom-center

- success
- info

- error

## API

### Propriedades Disponíveis

O componente `FreudToastComponent` possui as seguintes propriedades:

#### Propriedades Básicas
- **`position`**: Define a posição do toast na tela
  - Tipo: `'top-right' | 'top-left' | 'bottom-left' | 'bottom-right' | 'top-center' | 'bottom-center' | 'center'`
  - Padrão: `'top-right'`

- **`key`**: Chave única para identificar o toast
  - Tipo: `string`
  - Obrigatório: `true`

- **`url`**: URL para redirecionamento quando o toast for clicado
  - Tipo: `string`
  - Opcional: `true`

- **`targetParam`**: Define como abrir a URL
  - Tipo: `'_blank' | '_self' | '_top' | '_parent'`
  - Padrão: `'_blank'`

#### Propriedades de Acessibilidade
- **`ariaLabelledBy`**: Referencia o ID de outro elemento que descreve o componente
  - Tipo: `string`
  - Opcional: `true`

- **`ariaLabel`**: Fornece uma descrição mais detalhada do componente para leitores de tela
  - Tipo: `string`
  - Opcional: `true`
