## API

### Propriedades Disponíveis

O componente `FreudAlertMessagesComponent` possui as seguintes propriedades:

#### Propriedades Básicas
- **`messages`**: Array de mensagens a serem exibidas
  - Tipo: `FreudMessage[]`
  - Obrigatório: `true`

- **`severity`**: Define a gravidade da mensagem
  - Tipo: `'success' | 'info' | 'warn' | 'error'`
  - Padrão: `'success'`

- **`text`**: Texto da mensagem
  - Tipo: `string`
  - Obrigatório: `true`

- **`closable`**: Define se a mensagem pode ser fechada
  - Tipo: `boolean`
  - Padrão: `true`

#### Propriedades de Acessibilidade
- **`ariaLabelledBy`**: Referencia o ID de outro elemento que descreve o componente
  - Tipo: `string`
  - Opcional: `true`

- **`ariaLabel`**: Fornece uma descrição mais detalhada do componente para leitores de tela
  - Tipo: `string`
  - Opcional: `true`

### Interface FreudMessage

```typescript
interface FreudMessage {
  severity: 'success' | 'info' | 'warn' | 'error';
  summary: string;
  detail: string;
  icon?: string;
}
```
