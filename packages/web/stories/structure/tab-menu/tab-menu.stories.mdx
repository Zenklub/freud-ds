## Getting Started
FreudTabMenu requer uma coleção de itens de menu, para isso utilize a interface `FreudMenuItem`
```ts
import { FreudMenuItem } from '@freud-ds/web-components';

items: FreudMenuItem[] = [
  {label: 'Home', command: () => { /* Ação quando for clicado na opção */}},
  {label: 'Calendar', command: () => { /* Ação quando for clicado na opção */}},
  {label: 'Edit', command: () => { /* Ação quando for clicado na opção */}},
  {label: 'Documentation', command: () => { /* Ação quando for clicado na opção */}},
  {label: 'Settings', command: () => { /* Ação quando for clicado na opção */}}
]
```
```html
      <freud-tab-menu
          [items]="items"
          [activeItem]="items[0]"
          [bgColor]="bgColor">
</freud-tab-menu>
```

## <a id="api"></a>API

### Propriedades Disponíveis

O componente `FreudTabMenuComponent` possui as seguintes propriedades:

#### Propriedades Básicas
- **`items`**: Array de itens do menu
  - Tipo: `FreudMenuItem[]`
  - Obrigatório: `true`

- **`activeItem`**: Item ativo do menu
  - Tipo: `FreudMenuItem`
  - Obrigatório: `true`

- **`bgColor`**: Define se o menu deve ter cor de fundo
  - Tipo: `boolean`
  - Padrão: `false`

#### Propriedades de Acessibilidade
- **`ariaLabel`**: Fornece uma descrição mais detalhada do componente para leitores de tela
  - Tipo: `string`
  - Padrão: `''`

- **`ariaLabelledBy`**: Referencia o ID de outro elemento que descreve o componente
  - Tipo: `string`
  - Padrão: `''`

### Interface FreudMenuItem

```typescript
interface FreudMenuItem {
  label: string;
  command: () => void;
  icon?: string;
  disabled?: boolean;
}
```
