## Getting Started

FreudDialog é definido usando a tag freud-dialog e exibido/oculto pela propriedade `visible`.

Utilize o template `freudTemplatefooter` para exibir o footer do modal

```html
<freud-dialog header="Header" [(visible)]="visible">
  <p>Conteudo do modal</p>

  <ng-container freudTemplatefooter>
    <freud-button color="secondary" (click)="visible=false"
      >Cancelar</freud-button
    >
    <freud-button (click)="visible=false">Ok</freud-button>
  </ng-container>
</freud-dialog>
```

## <a id="api"></a>API

### Position

Utilize a propriedade `position` para posicionar o dialog, opções disponíveis:

- "center" (Padrão)
- "top"
- "bottom"
- "left"
- "right"
- "top-left"
- "top-right"
- "bottom-left"
- "bottom-right"

## API

### Propriedades Disponíveis

O componente `FreudDialogComponent` possui as seguintes propriedades:

#### Propriedades Básicas
- **`header`**: Define o cabeçalho do dialog
  - Tipo: `string`
  - Padrão: `''`

- **`modal`**: Define se o dialog é modal
  - Tipo: `boolean`
  - Padrão: `false`

- **`draggable`**: Define se o dialog pode ser arrastado
  - Tipo: `boolean`
  - Padrão: `true`

- **`resizable`**: Define se o dialog pode ser redimensionado
  - Tipo: `boolean`
  - Padrão: `false`

- **`showHeader`**: Define se deve mostrar o cabeçalho
  - Tipo: `boolean`
  - Padrão: `true`

- **`maximizable`**: Define se o dialog pode ser maximizado
  - Tipo: `boolean`
  - Padrão: `false`

- **`closable`**: Define se o dialog pode ser fechado
  - Tipo: `boolean`
  - Padrão: `true`

- **`position`**: Define a posição do dialog
  - Tipo: `'center' | 'top' | 'bottom' | 'left' | 'right' | 'topleft' | 'topright' | 'bottomleft' | 'bottomright'`
  - Padrão: `'center'`

#### Propriedades de Ícones
- **`closeIcon`**: Define o ícone do botão fechar
  - Tipo: `string`
  - Padrão: `'freud-icon freud-icon-times'`

- **`minimizeIcon`**: Define o ícone do botão minimizar
  - Tipo: `string`
  - Padrão: `'freud-icon freud-icon-window-minimize'`

- **`maximizeIcon`**: Define o ícone do botão maximizar
  - Tipo: `string`
  - Padrão: `'freud-icon freud-icon-window-maximize'`

#### Propriedades de Foco
- **`focusTrap`**: Define se deve capturar o foco
  - Tipo: `boolean`
  - Padrão: `true`

- **`focusOnShow`**: Define se deve focar ao mostrar
  - Tipo: `boolean`
  - Padrão: `true`

- **`closeOnEscape`**: Define se deve fechar ao pressionar ESC
  - Tipo: `boolean`
  - Padrão: `true`

#### Propriedades de Acessibilidade
- **`closeAriaLabel`**: Define o label de acessibilidade do botão fechar
  - Tipo: `string`
  - Padrão: `'Fechar modal'`

- **`closeTabindex`**: Define o tabindex do botão fechar
  - Tipo: `string`
  - Padrão: `'0'`
