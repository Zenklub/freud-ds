## <a id="api"></a>API

### Propriedades Disponíveis

O componente `FreudSwitchComponent` possui as seguintes propriedades:

#### Propriedades Básicas
- **`invalid`**: Define se o switch está em estado inválido
  - Tipo: `boolean`
  - Padrão: `false`

- **`disabled`**: Define se o switch está desabilitado
  - Tipo: `boolean`
  - Padrão: `false`

- **`name`**: Define o nome do switch
  - Tipo: `string`
  - Padrão: `''`

- **`falseValue`**: Define o valor quando desligado
  - Tipo: `any`
  - Padrão: `false`

- **`trueValue`**: Define o valor quando ligado
  - Tipo: `any`
  - Padrão: `true`

- **`required`**: Define se o switch é obrigatório
  - Tipo: `boolean`
  - Padrão: `false`

- **`id`**: Define o ID do componente
  - Tipo: `string`
  - Padrão: `''`

- **`custom`**: Define se o switch deve usar estilo customizado
  - Tipo: `boolean`
  - Padrão: `false`

#### Propriedades de Acessibilidade
- **`ariaLabelledBy`**: Referencia o ID de outro elemento que descreve o componente
  - Tipo: `string`
  - Opcional: `true`

- **`ariaLabel`**: Fornece uma descrição mais detalhada do componente para leitores de tela
  - Tipo: `string`
  - Opcional: `true`
